# Change: 增加三套界面模板选择

## Why

当前应用只有深浅配色切换，整体组件外观固定，设置页也没有可发现的界面风格入口。用户希望保留当前原生界面的同时，能够选择视觉层次更丰富的模板，并在重启后继续使用所选风格。

## What Changes

- 在设置面板增加“界面模板”区域，以带实时缩略预览的选择卡展示“原生”“极光”“琥珀”三套模板。
- “原生”完整保留当前界面；“极光”使用冷色渐变、半透明层级与柔和光晕；“琥珀”使用暖色强调、立体卡片、清晰边界与阴影。
- 模板选择在当前窗口立即生效并持久化，首次使用、无效记录或存储不可用时安全回退“原生”。
- 模板与现有深色/浅色切换相互独立，三套模板都支持两种配色，并保留状态色、日志级别色、关键词高亮和文本选择的可辨识性。
- 模板只改变视觉表达，不改变日志正文的字体指标、字段列宽、虚拟列表测量、功能布局与业务状态。
- 补充简体中文、英文、键盘操作、单选语义、窄窗口和减少动态效果支持。

## Impact

- Affected specs: `application-settings`
- Affected code: `src/App.tsx`、`src/components/TopBar.tsx`、`src/components/SettingsPanel.tsx`、`src/styles.css`、`src/i18n/messages.ts`、新增前端偏好存储工具及相关测试
- 不修改 Rust、Tauri IPC、日志解析/筛选语义、工作区 schema、安装器或发布流程
