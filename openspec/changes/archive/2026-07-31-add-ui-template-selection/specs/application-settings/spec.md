## ADDED Requirements

### Requirement: 界面模板偏好

系统 SHALL 在设置面板中提供“原生”“极光”“琥珀”三套界面模板，并以名称、说明、缩略预览和明确选中状态同时展示全部选项。“原生” MUST 保持变更前的现有界面视觉；“极光” MUST 使用冷色渐变、半透明层级和柔和光晕；“琥珀” MUST 使用暖色强调、立体卡片、清晰边界和阴影。模板 SHALL 作用于应用框架、顶栏、目录、选项卡、底栏、设置页、弹层和常用控件，但 MUST NOT 改变日志正文的字体指标、字段列宽、虚拟列表测量、功能布局、日志级别色、关键词高亮或文本选择语义。

#### Scenario: 首次使用保持原生界面

- **WHEN** 用户没有已保存模板偏好并启动应用
- **THEN** 系统选择“原生”，界面视觉与本能力加入前保持一致

#### Scenario: 设置页展示三套模板

- **WHEN** 用户打开设置面板并查看界面模板区域
- **THEN** 系统同时显示“原生”“极光”“琥珀”三张带名称、说明和缩略预览的选择卡，并明确标出当前模板

#### Scenario: 即时切换极光模板

- **WHEN** 用户点击或使用键盘选择“极光”
- **THEN** 当前窗口立即使用冷色渐变、半透明层级和柔和光晕，已打开日志、筛选条件、滚动位置和工作区状态保持不变

#### Scenario: 即时切换琥珀模板

- **WHEN** 用户点击或使用键盘选择“琥珀”
- **THEN** 当前窗口立即使用暖色强调、立体卡片、清晰边界和阴影，已打开日志、筛选条件、滚动位置和工作区状态保持不变

#### Scenario: 模板与深浅配色独立组合

- **WHEN** 用户选择任一界面模板后切换现有深色或浅色配色
- **THEN** 系统只改变配色而保留所选模板，且三套模板在两种配色下的文字、状态与交互焦点均清晰可辨

#### Scenario: 重启恢复模板

- **WHEN** 用户选择模板、关闭并重新启动应用
- **THEN** 系统在初始界面恢复该模板，不需要用户再次选择

#### Scenario: 无效偏好安全回退

- **WHEN** 模板偏好缺失、包含未知值或存储不可用
- **THEN** 系统安全使用“原生”并保持应用可启动、可切换，不显示无选中状态或空白界面

#### Scenario: 减少动态效果

- **WHEN** 操作系统启用了减少动态效果偏好
- **THEN** 系统保留三套模板的材质、层级、选中和焦点状态，但不执行模板切换、悬停或装饰渐变动画
