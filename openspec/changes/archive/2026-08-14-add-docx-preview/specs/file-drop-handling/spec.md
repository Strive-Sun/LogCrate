## ADDED Requirements

### Requirement: 拖入 DOCX 自动图文预览

系统 SHALL 在用户拖入单个结构有效的 `.docx` 后，沿用普通文件的父目录自动监控与定位流程，并立即创建该文档的简化图文预览会话。监控添加失败或父目录已受监控不得关闭已经成功创建的预览。

#### Scenario: 拖入有效 DOCX

- **WHEN** 用户拖入单个结构有效且可读的 `.docx`
- **THEN** 系统立即打开图文预览，同时添加或复用其父目录监控、定位并选中文档叶子节点

#### Scenario: 拖入 DOCX 不匹配筛选

- **WHEN** 有效 `.docx` 不匹配当前目录后缀筛选
- **THEN** 系统仍临时显示、定位并预览当前拖入文档，定位完成后清理自动展开状态且不改变其它筛选结果

#### Scenario: 拖入无效或不支持的 Word 文件

- **WHEN** 用户拖入伪造或损坏的 `.docx`、加密 Word 文档或旧二进制 `.doc`
- **THEN** 系统不创建预览会话，显示对应格式错误或暂不支持提示，并且不把该文件当作裸文本读取
