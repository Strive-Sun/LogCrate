# Change: 调整搜索快捷键并增加日志内关键词查找

## Why

当前 `Ctrl+F` 被用于打开全盘文件搜索，不符合用户在日志阅读界面中查找当前内容的常见操作习惯。全盘搜索应由明确的顶栏入口触发，而 `Ctrl+F` 应服务于当前日志内容。

## What Changes

- 移除 `Ctrl+F` 对顶栏全盘文件搜索页面的打开与关闭行为，全盘搜索改为点击顶栏“搜索”入口触发。
- 在存在活动日志选项卡时，使用 `Ctrl+F` 打开当前日志的轻量关键词查找弹窗并聚焦输入框。
- 查找弹窗提供关键词输入、查找按钮、Enter 执行、Escape/关闭按钮和匹配定位，并支持反向查找、全词匹配、区分大小写与循环查找选项。
- 没有活动日志时，`Ctrl+F` 不打开全盘搜索，也不产生无关页面跳转。
- 更新中英文提示、快捷键说明和回归测试。

## Impact

- 受影响规格：`file-search`、`log-viewing`。
- 受影响代码：`src/App.tsx`、顶栏与日志查看组件、国际化、Tauri 日志会话命令及相关测试。
- 不改变文件搜索索引、持久化数据或用户权限边界。
