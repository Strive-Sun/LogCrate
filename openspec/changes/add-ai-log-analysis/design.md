## Context

LogCrate 是 Tauri 2 + React/Rust 桌面应用。日志可能来自本地文件或压缩包，正文使用虚拟列表，只能从当前选区取得文本。项目当前没有 AI 供应商或密钥存储抽象。

## Goals / Non-Goals

- Goals: 提供 OpenAI Chat Completions 与 Responses 兼容接口配置、系统密钥链保存、用户确认后的选区分析、向右扩展且不覆盖主页面的对话栏、多轮追问以及明确的失败和隐私提示。
- Non-Goals: 不自动上传日志、不在后台持续分析、不实现 OpenAI 兼容格式之外的供应商专属协议、不把完整日志文件上传、不跨关闭或重启持久化对话、不承诺 AI 结论正确。

## Decisions

- Decision: 供应商配置增加 `protocol`（`chat_completions` 或 `responses`）、`endpoint_mode`（`base` 或 `full`）和 `allow_insecure_http`；继续配置 `name`、`base_url`、`model`，API Key 由 Rust 端读取。旧配置缺少新增字段时默认使用 Chat Completions、基础地址模式且不允许不安全 HTTP。
- Decision: 使用系统密钥链（Windows Credential Manager、macOS Keychain）保存密钥；前端只接收是否已配置，不接收或回显明文密钥。
- Decision: AI 请求由 Rust IPC 发起，前端发送选中文本和供应商 ID；Rust 根据协议和地址模式确定请求 URL：基础地址模式分别拼接 `/chat/completions` 或 `/responses`，完整 URL 模式不再拼接路径；两种协议均使用 Bearer API Key，限制文本长度并设置请求超时。
- Decision: 右键“AI 分析”先打开确认/分析面板，展示供应商、模型、端点主机、字符数和“内容将发送到远程服务”提示，确认后才发起请求。
- Decision: 分析结果按结构化 Markdown/JSON 解析为摘要、信息、警告、错误、可能原因和建议；无法解析时以安全纯文本展示。
- Decision: 首批提供 OpenAI、DeepSeek、通义千问和 OpenRouter 预设，同时允许用户添加自定义兼容端点。
- Decision: HTTPS 与 `localhost`、`127.0.0.1`、`::1` 的 HTTP 默认允许。其它 HTTP 地址默认拒绝；只有用户对当前供应商明确开启 `allow_insecure_http` 并确认风险后才允许，授权仅绑定该供应商和已保存端点，不形成全局 HTTP 放行。
- Decision: 测试连接按供应商协议向实际分析端点发送不含用户日志的最小请求，不再固定依赖 `/models`；Responses API 从 `output[].content[]` 的文本内容提取结果，Chat Completions 保持从 `choices[].message.content` 提取结果。
- Decision: AI 对话栏继续属于主窗口内容，但不覆盖或挤压打开前的日志主页面。首次打开时记录主窗口外部位置与尺寸，把原生窗口向右增加目标 440px，并给应用内容增加同宽右栏；若右侧工作区不足，则只把窗口向左移动所需距离。右栏允许在 360–440px 内适配；若当前显示器工作区仍无法同时容纳打开前主页面宽度与 360px 右栏，则显示明确错误且不发送日志。关闭 AI 对话栏时恢复记录的窗口边界。窗口已经最大化时先恢复为可调整窗口并按同一规则扩展，关闭后恢复打开前的最大化状态；不得退回覆盖正文的浮层。
- Decision: 前端只获得读取当前窗口边界和设置主窗口尺寸/位置所需的最小 Tauri 权限，不开放创建任意窗口或其它窗口管理能力。窗口扩展失败时保留日志页面并显示明确错误，不以覆盖主页面作为静默降级。
- Decision: 对话栏固定使用纯白不透明背景和深色文字，不继承会产生透明度的主题材质；头部、消息列表和底部追问输入组成完整对话布局，消息列表独立滚动。
- Decision: 首轮确认后，前端在当前内存中保存原始选区、供应商元数据和用户/助手消息；每次追问把原始选区、受限的历史消息和新问题交给 Rust，Rust 重新读取当前供应商密钥并按对应协议发送。关闭对话栏、切换为新的日志分析或应用退出时清除上下文，不写入 localStorage、普通配置、日志或仓库。
- Decision: Chat Completions 使用 system/user/assistant 消息序列；Responses 使用等价的有界对话输入。客户端不得提供 system 角色。原始选区最多 120,000 字符，新问题最多 4,000 字符，对话历史最多 12 条消息且总字符受限；超过限制时拒绝发送并提示开始新分析，不静默丢弃原始日志或最近问题。
- Decision: 初始确认明确告知原始选区会发送到目标端点；对话栏持续显示供应商、模型和“每次追问会再次发送原始选区与当前上下文”的提示。用户主动点击发送追问即构成该轮明确操作，不重复弹出系统确认；若供应商端点、协议或模型在会话期间发生变化，则停止当前会话并要求重新开始分析和确认。

## Single-Window Layout Design

- 主窗口是唯一 Tauri 窗口；React 根布局使用主区域与 AI 区域的并排容器。
- 打开 AI 时由主窗口 IPC 调整自身尺寸，AI 区域使用普通布局流（`flex`/`grid`），不使用 fixed、absolute 覆盖或独立 WebviewWindow。
- AI 区域顶栏承载历史下拉、标题和关闭按钮；消息区与输入区独立滚动/固定。
- 关闭 AI 时销毁当前 AI React 会话并通过 IPC 恢复主窗口打开前的位置、尺寸和最大化状态。

- 使用 Tauri 独立 WebviewWindow（固定 label：`ai-conversation`）承载 AI UI，主窗口只保留 AI 启动入口。
- AI 窗口目标宽度 440px、最小宽度 360px，与主窗口右边缘贴靠；主窗口本身不扩宽、不改变内容布局。
- AI 窗口使用独立白色不透明页面和独立关闭按钮；窗口关闭事件只销毁/隐藏 AI 窗口。
- AI 窗口使用 `decorations=false` 隐藏系统标题栏；应用顶栏设置 `data-tauri-drag-region`，并通过窗口移动事件同步主窗口位置。
- 位置同步以主窗口左上角和外部尺寸为基准：`ai.x = main.x + main.width`、`ai.y = main.y`；双向移动使用共享同步锁抑制递归事件。
- 主窗口尺寸变化时重新计算 AI 位置；AI 窗口关闭或同步失败时不改变主窗口。
- AI 页面通过既有安全 IPC 访问供应商、分析、追问和加密历史，不接收 API Key。
- 顶栏左侧历史按钮展开下拉列表，切换会话后恢复消息与追问上下文。

## Encrypted History Design

- 应用数据目录保存版本化历史文件，由 Rust 后端独占读写，前端只通过 IPC 访问。
- 每条记录使用随机 nonce 的 AES-256-GCM；完整日志、问题和回复均不得以明文落盘。
- 首次保存时生成随机 256-bit 主密钥并写入 Windows Credential Manager/macOS Keychain；密钥链失败即拒绝保存/恢复，不回退明文。
- 最多保留 100 条，达到上限提示删除；关闭抽屉仅释放内存会话，删除不承诺物理介质安全擦除。
- 恢复时比较端点、协议和模型指纹；不一致要求重新确认后才可继续追问。

- 第三方服务会获得用户选中的日志内容；通过明确确认、端点展示、长度限制和不自动发送降低风险。
- 内网 HTTP 会让 API Key 与日志内容在传输链路上缺少 TLS 保护；默认拒绝，并通过逐供应商显式授权、醒目警告和发送前再次展示 HTTP 目标降低误用风险，仍优先建议供应商提供 HTTPS。
- 系统密钥链在权限或平台 API 不可用时可能失败；配置界面必须显示不可用原因且不回退到明文存储。
- 不同兼容供应商响应格式可能不同；保留原始安全文本回退，不将响应内容写入日志。
- 每次追问重发原始选区和有界历史会增加请求体与第三方暴露范围；通过显式常驻提示、严格消息/字符上限和关闭即清除降低风险。
- 原生窗口扩展在最大化、多显示器、缩放或工作区边缘情况下存在平台差异；使用逻辑尺寸、当前显示器工作区和打开前边界恢复，并通过 Windows/macOS 真机覆盖正常、边缘、最大化和关闭恢复场景。

## Migration Plan

不迁移已有用户数据。首次使用时没有供应商配置；已有 localStorage 不读取任何 AI Key 字段。删除供应商时同时删除对应系统密钥链条目。

## Open Questions

无；右栏目标宽度为 440px、最小宽度为 360px，工作区无法容纳时按上述不覆盖主页面原则明确失败。
