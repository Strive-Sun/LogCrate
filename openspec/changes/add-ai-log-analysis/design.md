## Context

LogCrate 是 Tauri 2 + React/Rust 桌面应用。日志正文使用虚拟列表，AI 输入来自当前选区和用户明确选择的本地文本附件。前端负责确认、展示和交互，密钥、网络请求、附件读取和加密历史留在 Rust。

## Goals / Non-Goals

- Goals: 安全配置 OpenAI 兼容端点；仅在用户主动操作后发送；在主窗口中并排展示 AI；提供有界多轮追问、加密历史和文本附件。
- Non-Goals: 不自动或后台上传日志，不支持 OpenAI 兼容格式之外的专属协议，不支持二进制或归档附件，不承诺 AI 结论正确，不把密钥或历史明文写入普通配置和日志。

## Decisions

- 供应商配置包含 `protocol`、`endpoint_mode`、`allow_insecure_http`、名称、请求地址和模型。旧配置缺少新增字段时安全回退为 Chat Completions、基础地址模式和禁止不安全 HTTP。
- API Key 由 Rust 使用系统密钥链保存和读取；前端只接收 `keyConfigured`。密钥链失败时明确报错，不回退明文。
- Rust 根据协议和地址模式构造 `/chat/completions` 或 `/responses` 请求；完整 URL 不再拼接路径。测试连接使用不含用户日志的最小请求。
- HTTPS 与本机 HTTP 默认允许。其它 HTTP 只有在当前供应商显式授权后允许；授权不扩散到其它供应商或地址，发送前继续展示无 TLS 风险。
- AI 工作区是 React 根布局的右侧兄弟区域，主窗口是唯一产品窗口。打开前记录主窗口位置、客户区尺寸和最大化状态，在现有右侧空间中增加 360–440px 右栏；空间不足时明确失败。关闭时恢复快照。
- AI 工作区使用纯白不透明背景和深色文字；主工具栏属于左侧主页面并保持可见。消息区独立滚动，历史、关闭、加载、错误和 composer 由主页面生命周期管理。
- 当前会话绑定供应商 ID、协议、模型和端点指纹。目标变化时停止发送并要求重新确认。
- 原始选区最多 120,000 字符，新问题最多 4,000 字符；请求构造最多使用最近 12 条历史消息。原始选区与当前及已恢复附件正文共同执行 120,000 字符限制。
- 历史保存在应用数据目录的版本化 AES-256-GCM envelope 中，每次写入使用随机 nonce。随机 256-bit 主密钥只保存到系统密钥链。最多 100 条，达到上限时要求用户删除。
- 历史列表和普通前端视图只返回附件名称与字符数；附件正文只在 Rust 解密后用于恢复追问。
- composer 左侧“+”调用原生文件选择器，右侧向上箭头与 Enter 共用发送函数；Shift+Enter 和 IME composition 保留编辑行为。
- 附件只接受用户选择的规范化绝对路径，最多 5 个、单文件最多 256 KiB。Rust 有界读取并拒绝目录、重复路径、压缩归档、NUL/二进制、不可解码和不可读输入。
- 助手回复使用受限 React Markdown 节点渲染标题、段落、列表、行内代码和代码块，不启用任意 HTML；无法解析时安全回退纯文本。

## Risks / Trade-offs

- 第三方端点会获得用户主动发送的日志和上下文；通过发送前确认、目标提示、输入上限和禁止后台发送降低风险。
- 非本机 HTTP 缺少 TLS；默认拒绝，只允许逐供应商显式授权，并持续显示风险。
- 系统密钥链、应用数据目录或历史密文损坏会导致保存/恢复失败；错误必须脱敏且不得创建明文旁路。
- 当前窗口扩展依赖打开时已有的右侧工作区；更完整的边缘适配和双平台真机覆盖不属于本 change 的已完成范围，转入后续 change。

## Migration Plan

- 旧供应商配置按安全默认值迁移。
- 版本化加密历史兼容缺少附件字段的旧消息；无法认证或解密的历史明确失败。
