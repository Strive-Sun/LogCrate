# Change: 增加日志选区 AI 分析与供应商配置

## Why

用户需要将选中的日志交给 AI 快速梳理，了解日志包含的信息、警告、错误和可能原因。当前日志正文没有 AI 分析入口，也没有安全的供应商和 API Key 配置能力。

## What Changes

- 在日志正文选区右键菜单增加“AI 分析”。
- 增加 OpenAI 兼容接口供应商配置，支持供应商名称、API 请求地址、协议、地址模式、模型和 API Key。
- 同时支持 OpenAI Chat Completions 与 OpenAI Responses API；API 请求地址可作为基础地址自动拼接协议路径，也可作为完整 URL 使用。
- 默认仅允许 HTTPS 和本机 HTTP；用户可对明确配置的内网 HTTP 供应商单独开启不安全连接，并在保存与发送前看到风险警告。
- API Key 只保存到 Windows Credential Manager 或 macOS Keychain，不写入仓库、localStorage、普通配置文件、日志或错误信息。
- AI 分析仅在用户主动点击并确认后发送选中文本；界面显示目标端点、模型和文本规模。
- AI 分析打开时扩展原生主窗口，在不缩窄或覆盖原日志主页面的前提下，从右侧增加纯白、不透明的对话栏；关闭后恢复打开前窗口边界。
- 将一次性分析结果升级为内存态多轮对话：首轮分段展示摘要、日志信息、警告、错误、可能原因和建议，用户可继续追问更具体的问题。
- 每次追问只向当前会话选定的供应商发送原始选区、当前对话上下文和新问题；关闭或开始新的分析后清除上下文，不写入普通配置、日志或仓库。

## Separate AI Window Extension

- AI 对话不再渲染为主窗口内部的覆盖层或抽屉，而是创建独立原生窗口并排列在主窗口右侧。
- 主窗口的顶部 AI、主题、通知、设置以及全部日志内容保持原位置和可见范围，不被 AI 窗口覆盖或压缩。
- AI 窗口有独立标题栏和关闭按钮；关闭 AI 窗口不关闭或隐藏主窗口。
- AI 窗口顶栏左侧提供“历史对话”入口，点击后显示下拉列表并可切换历史会话。
- 主窗口移动或尺寸变化时，AI 窗口保持贴靠右侧；屏幕空间不足时明确失败，不覆盖主窗口。
- AI 窗口隐藏系统标题栏，使用应用自绘顶栏；顶栏同时作为窗口拖动区域，保留历史下拉和关闭按钮。
- 主窗口与 AI 窗口监听移动事件并互相同步位置，使用防递归同步锁，保证拖动任一窗口时另一窗口跟随。

## History Persistence Extension

- 对话历史保存到本地应用数据目录，不上传云端、不写 Git。
- 选中日志片段、用户问题、AI 回复及必要元数据必须加密保存。
- 随机加密主密钥只保存到 Windows Credential Manager 或 macOS Keychain；密钥链不可用时明确失败，禁止回退明文。
- UI 提供历史列表、打开/恢复并继续追问、删除单条、清空全部；关闭对话不删除历史。
- 历史最多保留 100 条，达到上限时提示用户删除，不静默丢弃。
- 恢复历史后重新确认供应商、协议和模型；目标发生变化时不得静默发送旧日志上下文。

## Impact

- Affected specs: `application-settings`, `log-viewing`
- Affected code: React 设置面板、日志上下文菜单和 AI 对话栏，Tauri 主窗口尺寸/位置权限，AI IPC，Rust 系统密钥链与协议感知 HTTP 客户端
- 安全边界：选中的日志内容及当前对话上下文会按用户明确操作发送给所配置的第三方端点；API Key 不进入前端持久化、Git 或应用日志，对话不跨关闭或重启持久化。
