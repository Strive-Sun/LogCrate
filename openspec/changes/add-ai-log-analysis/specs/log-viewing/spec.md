## ADDED Requirements

### Requirement: 选中日志的 AI 分析

系统 SHALL 在日志正文选区右键菜单提供“AI 分析”。系统 MUST 仅在用户明确确认后，将当前选中文本发送到所选 OpenAI 兼容端点，并展示摘要、信息、警告、错误、可能原因和建议；系统不得自动上传完整文件或后台发送日志。

#### Scenario: 确认分析选区

- **WHEN** 用户选中文本、点击“AI 分析”并确认发送目标与文本规模
- **THEN** 系统使用已配置供应商发起一次分析请求，并在面板中展示结构化分析结果

#### Scenario: 发送前取消

- **WHEN** 用户在确认面板取消分析
- **THEN** 系统不发起网络请求，选区和日志视图保持不变

#### Scenario: 请求失败或响应不可解析

- **WHEN** 端点请求超时、返回错误或响应不是预期格式
- **THEN** 系统显示可理解的失败状态或安全纯文本回退，不泄露 API Key，不将完整响应写入应用日志

#### Scenario: 未配置供应商

- **WHEN** 用户点击“AI 分析”但没有可用供应商
- **THEN** 系统引导用户进入供应商设置，不发送选中文本
