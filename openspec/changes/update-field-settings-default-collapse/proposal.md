# Change: 字段设置默认收起

## Why

字段筛选弹层当前会直接展开名称、类型和字段结构等设置，占用较多空间并分散日常筛选操作的注意力。用户希望所有字段的设置区域默认收起，仅在需要调整字段布局时再主动展开。

## What Changes

- 所有字段类型的筛选弹层中，“字段设置”区域默认收起，只保留可操作的标题入口。
- 用户可通过字段设置标题显式展开或再次收起名称、类型、拆分和合并控件。
- 关闭当前字段弹层或切换到其它字段后，下一次打开任意字段弹层时字段设置重新保持默认收起。
- 字段值、时间范围和文本条件等主要筛选控件维持现有展示与行为。

## Impact

- Affected specs: `log-viewing`
- Affected code: `src/components/LogFieldFilterBar.tsx`、相关国际化文案、组件测试与样式
