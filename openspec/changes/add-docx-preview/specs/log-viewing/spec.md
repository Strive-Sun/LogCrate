## ADDED Requirements

### Requirement: DOCX 简化图文预览

系统 SHALL 在现有选项卡工作区中以独立 DOCX 视图预览主文档正文与包内 PNG/JPEG。预览 SHALL 按主文档阅读顺序合并 `w:t` 文本，保留段落、空段落、显式换行和制表符；表格 SHALL 每行映射为一个文本块、单元格之间使用制表符、单元格内多个段落使用单个空格连接。图片 SHALL 出现在引用它的段落锚点附近并按块参与动态虚拟滚动。正文查找 SHALL 复用现有大小写、全词、方向和循环语义，但不提供日志行号、编码重建或字段筛选。

#### Scenario: 预览普通段落

- **WHEN** DOCX 主文档包含跨多个文本 run 的连续文字、多个段落、空段落、显式换行和制表符
- **THEN** 系统按阅读顺序合并 run，段落和显式换行形成预览换行，空段落保留为空行，制表符保留为制表符

#### Scenario: 预览表格

- **WHEN** DOCX 主文档包含多行多列表格且单元格内可能含多个段落
- **THEN** 每个表格行形成一个预览行，相邻单元格以单个制表符分隔，单元格内段落以单个空格连接

#### Scenario: 显示内嵌与浮动截图

- **WHEN** 主文档段落通过 `wp:inline` 或 `wp:anchor` 引用有效 PNG/JPEG
- **THEN** 预览在该段落锚点附近按文档顺序显示图片，保持纵横比且宽度不超过正文区域；浮动图片按块显示，不还原绝对坐标或文字环绕

#### Scenario: 图片替代文字

- **WHEN** DOCX 为图片提供名称、描述或替代文字
- **THEN** 预览将其作为图片说明和无障碍名称，并允许该文本参与正文查找

#### Scenario: 虚拟化浏览与查找

- **WHEN** 用户滚动或查找较大 DOCX 图文预览
- **THEN** 系统分页读取块并动态测量可见文本/图片高度，导航到匹配文本所在块，不一次性向前端发送、解码或渲染完整文档及全部图片

#### Scenario: 简化图片与版式

- **WHEN** DOCX 包含字体/样式、精确分页、浮动环绕、图表、公式、批注、修订删除内容、字段指令、页眉页脚、脚注尾注、嵌入对象、宏或非 PNG/JPEG 图片
- **THEN** 首版不还原或执行这些能力；可见正文和支持图片继续显示，不支持图片在原锚点显示占位，界面明确这是简化预览

#### Scenario: 不支持旧 DOC

- **WHEN** 用户尝试打开旧二进制 `.doc` 或其它非 DOCX Word 格式
- **THEN** 系统不将其识别为 DOCX 预览，并明确提示该格式暂不支持

#### Scenario: DOCX 不显示日志专用控件

- **WHEN** DOCX 图文会话处于活动选项卡
- **THEN** 正文固定使用 UTF-8，界面不显示编码重建、日志字段筛选或行号控件，且用户操作不得以其它编码重新解释 DOCX 源包或转换流
