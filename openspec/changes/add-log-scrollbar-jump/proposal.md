# Change: 日志正文滚动条点击轨道直接跳转

## Why

在日志正文右侧滚动条的空白轨道上点击时，浏览器原生行为是每次向点击方向翻一页，按住时一页一页地慢慢移动，直到滑块到达鼠标位置。大日志有成千上万页，想跳到中后段需要反复点击或长时间按住。用户希望点击轨道后，滑块和正文直接跳到点击的位置。

## What Changes

- 日志正文的纵向滚动条改为应用自绘：点击滑块以外的轨道时，滑块中心直接移到点击位置，正文同步跳到对应位置；按住不放继续移动鼠标时，滑块跟随拖动。
- 拖动滑块、滚轮、触控板、键盘滚动的行为保持不变。滚动条外观沿用现有尺寸：宽 18px、滑块可见约 12px、最小长度 48px，颜色仍随界面模板与深浅色主题变化。
- 自动显示与渐隐保持现状：滚动时显示，停止约 0.7 秒后淡出；减少动态效果时不播放渐隐动画。另外，鼠标悬停在正文右侧滚动条区域时立即显示滑块，方便看清位置再点击；移出后淡出。
- 日志横向滚动条和应用其它区域（目录树、标签菜单、更新说明）的滚动条保持浏览器原生行为不变。

## Impact

- Affected specs: `application-interface`（新增日志正文滚动条点击跳转需求）。
- Affected code: `src/components/LogContent.tsx`、新增 `src/components/LogScrollbar.tsx` 与 `src/util/scrollbarGeometry.ts`、`src/styles.css` 及对应前端测试。
- 不改变 Tauri 命令、事件、Rust 实现或依赖。
