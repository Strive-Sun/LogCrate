# Change: 增加日志查找关键词高亮

## Why

当前日志内查找只高亮后端返回的单个当前关键词，用户无法在正文中同时辨认同一关键词的其它出现位置，也难以区分普通关键词与当前导航到的关键词。

## What Changes

- 查找弹窗打开且关键词非空时，只为日志正文中与输入关键词匹配的文本片段添加背景；匹配所在行和其它文本不着色。
- 普通关键词匹配使用黄色背景；当前查找操作定位到的关键词使用不同的主题强调色，并在继续查找后把上一个当前关键词恢复为普通黄色。
- 保持现有正向、反向、循环、定位和单匹配后端查找协议不变；全部匹配高亮只处理已经按窗口加载到前端的日志行。
- 切换关键词或匹配选项时立即刷新普通匹配高亮；关闭查找弹窗后移除普通匹配高亮，但保留现有当前匹配标记和滚动位置。
- 增加关键词片段范围、重复关键词、当前关键词区分、选项切换和虚拟列表渲染回归测试。

## Impact

- 受影响规格：`log-viewing`。
- 依赖 change：已完成但尚未归档的 `update-log-search-shortcut`。
- 受影响代码：`src/components/LogContent.tsx`、`src/components/LogRow.tsx`、前端匹配工具、`src/styles.css` 及相关测试。
- 不改变 Tauri IPC、Rust 日志索引、文件格式、持久化数据或权限边界。
