## Requirements
### Requirement: 设置面板

系统 SHALL 在用户点击顶栏设置按钮时打开设置面板，并允许用户通过再次点击设置按钮、点击面板外区域或按 Escape 关闭面板。设置面板 SHALL 展示版本、语言和更新选项。

#### Scenario: 打开并关闭设置面板

- **WHEN** 用户点击顶栏设置按钮
- **THEN** 系统显示设置面板及其中的版本、语言和更新选项
- **WHEN** 用户点击面板外区域或按 Escape
- **THEN** 系统关闭设置面板

### Requirement: 当前版本展示

系统 SHALL 在设置面板中展示当前运行构建的应用版本，且该版本 MUST 来自 Tauri 应用元数据而不是前端重复维护的常量。

#### Scenario: 查看当前版本

- **WHEN** 用户打开设置面板
- **THEN** 系统以 `X.Y.Z` 格式展示当前运行版本

### Requirement: 界面语言偏好

系统 SHALL 提供“跟随系统、简体中文、English”三种界面语言偏好并持久化用户选择。跟随系统时，中文系统语言 SHALL 映射到简体中文，其它未支持系统语言 SHALL 回退英文。语言选择变化 SHALL 在当前进程内立即生效，并同步 HTML 语言属性与原生托盘菜单，不要求重启应用。

#### Scenario: 首次启动跟随中文系统

- **WHEN** 用户没有已保存语言偏好且操作系统首选语言为任一中文 locale
- **THEN** 系统选择“跟随系统”并使用简体中文界面

#### Scenario: 首次启动跟随其它系统语言

- **WHEN** 用户没有已保存语言偏好且操作系统首选语言不是受支持的中文 locale
- **THEN** 系统选择“跟随系统”并使用英文界面

#### Scenario: 手动切换语言

- **WHEN** 用户在设置中选择简体中文或 English
- **THEN** 当前窗口、弹窗、可访问性标签和托盘菜单立即切换到所选语言，已打开文件与查看状态保持不变

#### Scenario: 重启恢复选择

- **WHEN** 用户保存语言偏好后重新启动应用
- **THEN** 系统恢复该偏好并解析实际语言，不需要用户再次选择

#### Scenario: 无效偏好安全回退

- **WHEN** 持久化语言值缺失、损坏或存储不可用
- **THEN** 系统安全回退“跟随系统”，且应用可正常启动和切换语言

### Requirement: 搜索功能启用偏好

系统 SHALL 在设置面板提供“启用文件搜索”开关。缺少有效偏好时该开关 SHALL 默认关闭。开关变化 SHALL 只保存下一次启动的目标状态，当前进程的搜索生命周期 MUST NOT 立即改变；每次成功开启或关闭后，系统 MUST 明确提示该变化将在下次启动时生效。

#### Scenario: 首次查看搜索设置

- **WHEN** 用户首次安装或没有有效的搜索功能偏好并打开设置
- **THEN** “启用文件搜索”开关显示为关闭，当前进程不启动搜索后台工作

#### Scenario: 开启搜索

- **WHEN** 用户将“启用文件搜索”从关闭切换为开启
- **THEN** 系统保存下次启动启用搜索的偏好并提示下次启动时生效，本次运行仍保持搜索关闭

#### Scenario: 关闭搜索

- **WHEN** 当前进程的搜索已启用且用户将“启用文件搜索”从开启切换为关闭
- **THEN** 系统保存下次启动关闭搜索的偏好并提示下次启动时生效，本次运行仍可继续搜索直至退出

#### Scenario: 保存失败

- **WHEN** 搜索功能偏好无法持久化
- **THEN** 系统保留切换前的已保存偏好、恢复开关显示并提供可读错误

#### Scenario: 重启应用偏好生效

- **WHEN** 用户更改搜索偏好后退出并重新启动 LogCrate
- **THEN** 系统将已保存偏好冻结为当前进程搜索有效状态，设置不再显示该变化为待重启

### Requirement: 界面模板偏好

系统 SHALL 在设置面板中提供“原生”“极光”“琥珀”“森绿”四套界面模板，并以名称、说明、缩略预览和明确选中状态同时展示全部选项。“原生” MUST 保持变更前的现有界面视觉；“极光” MUST 使用冷色渐变、半透明层级和柔和光晕；“琥珀” MUST 使用暖色强调、立体卡片、清晰边界和阴影；“森绿” MUST 使用森林绿与薄荷绿强调色、柔和自然渐变、清晰边界和克制阴影。模板 SHALL 作用于应用框架、顶栏、目录、选项卡、底栏、设置页、弹层和常用控件，但 MUST NOT 改变日志正文的字体指标、字段列宽、虚拟列表测量、功能布局、日志级别色、关键词高亮或文本选择语义。

#### Scenario: 首次使用保持原生界面

- **WHEN** 用户没有已保存模板偏好并启动应用
- **THEN** 系统选择“原生”，界面视觉与本能力加入前保持一致

#### Scenario: 设置页展示四套模板

- **WHEN** 用户打开设置面板并查看界面模板区域
- **THEN** 系统同时显示“原生”“极光”“琥珀”“森绿”四张带名称、说明和缩略预览的选择卡，并明确标出当前模板

#### Scenario: 即时切换极光模板

- **WHEN** 用户点击或使用键盘选择“极光”
- **THEN** 当前窗口立即使用冷色渐变、半透明层级和柔和光晕，已打开日志、筛选条件、滚动位置和工作区状态保持不变

#### Scenario: 即时切换琥珀模板

- **WHEN** 用户点击或使用键盘选择“琥珀”
- **THEN** 当前窗口立即使用暖色强调、立体卡片、清晰边界和阴影，已打开日志、筛选条件、滚动位置和工作区状态保持不变

#### Scenario: 即时切换森绿模板

- **WHEN** 用户点击或使用键盘选择“森绿”
- **THEN** 当前窗口立即使用森林绿与薄荷绿强调色、柔和自然渐变、清晰边界和克制阴影，已打开日志、筛选条件、滚动位置和工作区状态保持不变

#### Scenario: 模板与深浅配色独立组合

- **WHEN** 用户选择任一界面模板后切换现有深色或浅色配色
- **THEN** 系统只改变配色而保留所选模板，且四套模板在两种配色下的文字、状态与交互焦点均清晰可辨

#### Scenario: 重启恢复模板

- **WHEN** 用户选择模板、关闭并重新启动应用
- **THEN** 系统在初始界面恢复该模板，不需要用户再次选择

#### Scenario: 无效偏好安全回退

- **WHEN** 模板偏好缺失、包含未知值或存储不可用
- **THEN** 系统安全使用“原生”并保持应用可启动、可切换，不显示无选中状态或空白界面

#### Scenario: 减少动态效果

- **WHEN** 操作系统启用了减少动态效果偏好
- **THEN** 系统保留四套模板的材质、层级、选中和焦点状态，但不执行模板切换、悬停或装饰渐变动画

### Requirement: AI 供应商配置与密钥安全

系统 SHALL 提供 OpenAI 兼容接口供应商的名称、API 请求地址、协议（Chat Completions 或 Responses）、地址模式（基础地址或完整 URL）、模型和逐供应商不安全 HTTP 授权配置；API Key MUST 仅保存于当前平台系统密钥链，前端、localStorage、普通配置文件、Git 和应用日志中不得出现明文 API Key。系统 MUST 默认拒绝非本机 HTTP 地址，且仅在用户对当前供应商明确确认风险后允许该供应商使用已保存的 HTTP 端点。

#### Scenario: 保存供应商密钥

- **WHEN** 用户在设置中输入供应商信息和 API Key 并保存
- **THEN** 系统将非敏感配置保存到应用设置，将 API Key 写入系统密钥链，并仅返回已配置状态

#### Scenario: 删除供应商

- **WHEN** 用户删除已配置供应商
- **THEN** 系统删除对应系统密钥链条目和非敏感配置，且后续读取不会返回旧密钥

#### Scenario: 密钥链不可用

- **WHEN** 系统密钥链不可用或访问被拒绝
- **THEN** 系统显示明确错误，不回退到明文存储，也不将密钥写入日志

#### Scenario: 配置 Responses API 请求地址

- **WHEN** 用户选择 Responses 协议并填写基础 API 请求地址或完整 URL
- **THEN** 系统保存协议和地址模式，并明确展示最终请求目标的生成方式

#### Scenario: 默认拒绝内网 HTTP

- **WHEN** 用户填写非本机 HTTP API 请求地址但未开启当前供应商的不安全 HTTP 授权
- **THEN** 系统拒绝保存或连接，并提示 API Key 与日志内容缺少 TLS 保护

#### Scenario: 明确允许当前供应商使用 HTTP

- **WHEN** 用户对当前供应商开启不安全 HTTP、阅读风险提示并明确确认
- **THEN** 系统只允许该供应商使用其已保存的 HTTP 端点，并保留可见的不安全状态，不放行其它供应商或地址
