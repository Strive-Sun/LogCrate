# LogCrate 项目配置

本文档只保存稳定的项目概览、架构边界、关键目录、常用命令和文档路由。具体需求、设计、实施步骤与验证规则按任务读取对应权威文档，不在这里展开。

## 项目概览

LogCrate 是基于 Tauri 2 的 Windows/macOS 本地桌面日志工具：React 18 + TypeScript 负责 WebView 界面，Rust 负责文件系统、归档、日志索引、全盘文件搜索和平台能力。

核心链路有两条：

1. 日志查看：监控目录或拖入文件 → 稳定性与权限检查 → 归档/普通文件读取 → 行索引与窗口加载 → Tauri IPC → React 虚拟滚动。
2. 文件搜索：本地卷或目录发现 → 平台 provider → SQLite/Tantivy 索引与恢复 → Tauri 命令和进度事件 → 搜索界面。

前端只负责展示和交互；归档解析、全盘扫描、持久化和重 IO 必须留在 Rust。日志读取、索引和搜索均在本机完成，GitHub 仅用于源码、发布产物和应用更新。

## 关键目录

- `src/`：React/TypeScript 前端、国际化、Tauri API 边界和前端测试。
- `src-tauri/src/lib.rs`：Tauri 应用组装、共享状态、命令、插件和生命周期入口。
- `src-tauri/src/watcher.rs`：目录监控、文件稳定性和工作区相关协调。
- `src-tauri/src/archive/`、`src-tauri/src/index.rs`：归档读取、编码、日志行索引和窗口化加载。
- `src-tauri/src/search.rs`、`src-tauri/src/search_index.rs`：本地文件发现、索引生命周期、持久化和查询。
- `src-tauri/src/ntfs/`、`src-tauri/src/bin/logcrate_index_service.rs`：Windows MFT/USN、IPC 和可选索引服务。
- `src-tauri/src/macos_file_access.rs`：macOS 文件访问授权。
- `src-tauri/tauri.conf.json`：窗口、打包、资源与更新配置。
- `openspec/specs/`：已生效行为；`openspec/changes/`：活动与归档变更。
- `docs/`：技术设计、协作流程和专题测试说明；`scripts/`：发布、品牌和性能工具。
- `resources/`、`binaries/`：随应用分发的资源或二进制；`.github/workflows/`：CI 与发布流程。

`dist/`、`target/`、`.tauri-dev-dist/`、`node_modules/` 和临时测试目录是生成物，不作为项目事实或手工修改入口。

## 常用命令

以下命令从仓库根目录运行；完整门禁以 `规则手册/Step-4/验证规则.md` 为准。

- 安装依赖：`npm install`。CI 使用它规避 npm 平台可选依赖问题，不默认改用 `npm ci`。
- 前端开发：`npm run dev`。
- 桌面开发：`npm run tauri:dev`；Vite HMR：`npm run tauri:dev:hmr`。
- 前端检查：`npm test`、`npx tsc --noEmit`、`npm run lint`、`npm run format:check`、`npm run build`。
- Rust 检查：`cargo test --manifest-path src-tauri/Cargo.toml`、`cargo fmt --manifest-path src-tauri/Cargo.toml --all --check`、`cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings`、`cargo check --manifest-path src-tauri/Cargo.toml --all-targets`。
- 桌面构建：`npm run tauri:build`；发布检查：`npm run release:check`、`npm run brand:check`。

命令最终以 `package.json`、`src-tauri/Cargo.toml`、`.github/workflows/` 和工具帮助为准。

## 稳定约束

- 已生效公共行为以 `openspec/specs/` 为准；已批准活动 change 描述待实施行为；代码和配置反映当前实现现场。
- 新能力、公共行为变化、破坏性变更、架构调整及重大性能/安全工作先走 OpenSpec。
- IPC 命令、事件或序列化字段变化必须同时核对 `src/api/`、`src-tauri/src/lib.rs` 和相关 Rust 模块。
- Windows 与 macOS 的公共行为应保持一致；平台优化不能改变权限边界、结果正确性或失败语义。
- 大日志和大索引必须流式、分页、窗口化或使用受控缓存，不得将整包、整文件或全量结果一次性载入内存。
- 规则、规格、设计、配置和代码无法消解冲突时，停止实施并请求维护者确认。
